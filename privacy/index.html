隐私政策

本站重视访问者的隐私。本政策说明小明同学博客（xiaomingclassmate.com，以下简称“本站”）会使用哪些服务、可能处理哪些信息，以及你可以如何管理这些信息。

一、适用范围

本政策适用于本站页面及其提供的在线工具。本站链接到的第三方网站、GitHub 仓库和其他外部服务不受本政策约束，请查看相应服务的隐私政策。

二、本站直接处理的信息

本站是静态博客，不提供账号注册、支付或主动收集姓名、电话号码、精确位置等功能。

  • 在线工具默认在浏览器本地处理输入内容，不会把工具输入的数据上传到本站服务器。
  • 如果你通过评论功能发表内容，评论会由第三方评论服务处理；其中可能显示你的公开账号信息、评论正文和发表时间。
  • 服务器和内容分发网络可能为安全、故障排查和访问统计记录 IP 地址、浏览器类型、访问时间、请求页面和来源地址等常规日志。

三、Cookie 与本地存储

本站及第三方服务可能使用 Cookie、Local Storage 或类似技术，用于：

  • 记住夜间模式、侧栏状态等界面偏好；
  • 记录隐私同意选择；
  • 统计访问情况并衡量内容效果；
  • 由广告服务展示、限制或衡量广告。

你可以通过浏览器设置删除或阻止 Cookie。阻止部分 Cookie 后，主题偏好、评论或广告等功能可能无法正常工作。

四、Google 广告与分析

本站使用 Google AdSense、Google Tag Manager 和 Google Analytics 4。

  • Google 及其合作伙伴可能使用 Cookie，根据你访问本站或其他网站的情况展示和衡量广告。
  • Google 使用广告 Cookie 后，Google 及其合作伙伴可以根据用户对本站或互联网上其他网站的访问情况投放广告。
  • 你可以访问 Google 广告设置 管理个性化广告，也可以访问 AboutAds 了解行业退出选项。
  • 关于 Google 如何处理合作网站的信息，请查看 Google 隐私权政策。

在适用法律要求同意的地区，本站应通过意见征求提示取得广告、分析和相关 Cookie 所需的同意，并提供拒绝或更改选择的入口。你始终可以清除本站的浏览器存储后重新访问，以重新作出选择。

五、评论与第三方服务

本站可能使用或加载以下第三方服务。它们会按照各自的隐私政策处理必要的连接信息：

  • GitHub 与 Utterances：用于评论；登录 GitHub 后发表评论时，相关信息由 GitHub 处理。
  • Cloudflare：用于 DNS、内容分发、安全防护和访问分析。
  • Busuanzi：用于页面浏览量统计。
  • 静态资源 CDN：用于加载部分脚本、样式或图片。
  • 天气组件：用于在页面中展示天气信息。

本站不会主动把这些服务收集的信息汇总成包含姓名、联系方式或精确位置的用户档案。

六、信息的使用与保留

相关信息只用于提供页面和在线工具、保障安全、排查故障、了解内容使用情况、改善站点，以及按适用规则展示和衡量广告。第三方服务保存日志和 Cookie 的期限由各服务自身的设置和政策决定。

本站不会出售访问者的个人信息。除依法需要提供、保护本站或用户安全，或由上述服务按各自政策处理外，本站不会主动向无关第三方披露访问者信息。

七、安全

本站通过 HTTPS、访问控制、备份和最小化配置保护站点。但互联网传输和第三方服务不存在绝对安全，请勿在评论或公开页面提交密码、证件号码、支付信息等敏感内容。

八、儿童隐私

本站内容面向一般技术读者，不面向儿童主动收集个人信息。如果你认为儿童向本站或评论服务提交了个人信息，请通过下方方式联系处理。

九、你的选择

  • 使用浏览器设置管理或删除 Cookie；
  • 使用 Google 广告设置管理个性化广告；
  • 在意见征求提示中接受、拒绝或更改相关选择；
  • 对公开评论内容，可通过对应 GitHub 账号或评论入口管理；
  • 如需查询、更正或删除你主动提供给本站的信息，请通过本站 GitHub 仓库的 Issues 联系。

十、政策更新

当本站新增统计、评论、广告或其他第三方服务时，本政策可能同步更新。更新时间和内容以本页面显示为准。
