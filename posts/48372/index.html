告别简陋！打造高颜值 NAS 导航面板：Sun-Panel 实战教程

发表于2025-06-08|更新于2026-11-08|NAS
|总字数:1172|阅读时长:5 分钟|浏览量:

还在用简陋的网页管理 NAS 服务？ Sun-Panel 是一款开源、美观、易用的 NAS 导航面板，可以把常用网站、Docker 容器和自建服务集中到一个页面中。

本文以极空间 Z4 Pro 为例，演示 Sun-Panel 的 Docker 部署、基础配置和应用管理。

项目地址：https://github.com/hslr-s/sun-panel

版本提示： 本文截图和示例来自 2025 年 6 月，软件界面、默认账号和镜像版本可能已经变化。请使用官方最新稳定版，并以首次启动页面和官方文档为准。生产环境不建议长期使用 latest，应固定具体版本并定期升级。

为什么选择 Sun-Panel？

  • 界面简洁： 提供现代、清爽的导航面板；
  • 集中管理： 把网站、NAS 应用和 Docker 服务放在同一个入口；
  • 高度自定义： 支持分组、排序、自定义图标和主题；
  • Docker 部署： 可以通过 Docker Compose 快速启动；
  • 开源免费： 可以自行部署和修改。

准备工作

开始前需要准备：

  • 一台已经安装 Docker 的 NAS 或服务器；
  • Docker Compose；
  • 用于远程连接设备的 SSH 客户端。

安装 Sun-Panel

1. 创建数据目录

在 NAS 的 Docker 数据目录中，为 Sun-Panel 创建一个用于保存配置的目录。

2. 使用 Docker Compose 部署

打开极空间的 Docker → Compose → 新增项目，将下面内容填入 Compose 配置。

记得把左侧的配置目录替换成自己的绝对路径。极空间可以通过 Compose 的“查询路径”功能获取目录路径。

点击创建并等待镜像拉取完成。

如果 3002 端口已被占用，可以修改冒号左侧的宿主机端口。

安全提示： 挂载 /var/run/docker.sock 等于把 Docker 管理权限交给容器，只应部署可信镜像并限制面板访问。不需要 Docker 管理功能时，可以删除这条挂载。

3. 登录 Sun-Panel

示例中的默认账号为 admin@sun.cc，默认密码为 12345678。不同版本可能调整默认值，请以首次启动页面和官方文档为准。

登录后立即修改默认账号和密码。

配置 Sun-Panel

1. 个性化设置

点击右上角的系统应用，进入“个性化设置”，可以调整面板背景、主题和其他显示选项。

2. 添加分组

创建一个网站分组，用于整理常用服务。

3. 添加网站应用

点击分组旁的“添加+”按钮，填写应用名称、URL 和分组，然后获取图标并保存。

4. 添加 Docker 应用

进入 设置 → Docker，点击对应容器旁的“+”号，填写内网 IP、端口和图标。

5. 编辑应用

将鼠标悬停在应用图标上，点击“编辑”即可修改名称、地址、图标和分组。

6. 排序应用

直接拖拽应用图标，就能调整它们在导航面板中的位置。

7. 自定义主题与 CSS

可以在个性化设置中上传背景图片，也可以通过自定义 CSS 进一步调整外观。

详细配置请参考 Sun-Panel 官方文档。

使用 Sun-Panel

配置完成后，点击面板上的应用即可跳转到对应服务，不必再记端口号。

需要 Docker 管理功能时，可以右键点击 Docker 图标启动或停止容器。

高级技巧与安全建议

  • 使用反向代理绑定域名并启用 HTTPS；
  • 为应用添加自定义图标；
  • 将多个 NAS 服务集中到同一个 Compose 项目；
  • 不要把 3002 管理端口直接暴露到公网，优先使用 VPN、内网访问或访问控制；
  • 定期备份 Sun-Panel 的 conf 目录；
  • 固定镜像版本，升级前先查看版本说明并备份配置。

总结

Sun-Panel 把常用网站、Docker 容器和 NAS 服务整合到一个高颜值面板中，部署和日常使用都比较简单。真正需要重视的是默认密码、Docker Socket 权限和管理入口的网络暴露范围。

现在就可以用自己的 NAS 搭一个统一入口，让日常访问和管理更顺手。
