别再忍了！uv 下载慢如龟速？一招配置国内镜像，让你的 Python 体验坐上火箭！

|总字数:773|阅读时长:3 分钟|浏览量:

最近很多 Python 开发者都在试用 uv。它用 Rust 编写，依赖解析和缓存很快，但如果你直接执行：

仍可能看到下载进度缓慢。问题通常不在 uv，而在默认 PyPI 源到本地网络之间的链路。

版本提示： 本文截图和命令来自 2025 年 7 月。uv 的配置项可能随版本调整，操作前请先查看当前版本文档。

慢在哪里？

uv 的优势主要体现在依赖解析、并行下载、缓存和本地安装流程。但它下载包时依然要走网络。

默认情况下，uv 与 pip 一样从官方 PyPI 下载包。国内访问官方源时可能较慢，这时 uv 再快，也会被网络链路拖住。

解决思路很简单：把包索引切换到国内镜像，例如清华 TUNA、阿里云等。

验证是否生效

如果日志里出现 pypi.tuna.tsinghua.edu.cn，而不是 pypi.org，说明镜像配置已生效。

镜像选择和安全提示

  • 清华源：https://pypi.tuna.tsinghua.edu.cn/simple
  • 阿里源：https://mirrors.aliyun.com/pypi/simple/

镜像源会同步 PyPI 包，但同步可能存在延迟。如果某个包刚发布，官方源可能比镜像更早可用。

不要随意使用来历不明的镜像。包索引是供应链安全的关键入口，个人环境也建议只使用学校、企业或云厂商等可信镜像。

总结

  • 临时使用：命令行加 --default-index；
  • 个人默认：配置 UV_DEFAULT_INDEX；
  • 团队统一：写入 pyproject.toml；
  • 配好后用 uv pip install -v requests 检查实际下载源。

把网络这一环解决掉，uv 的速度优势才能真正发挥出来。
