内网穿透系列（二）：告别黑窗口！frpc-desktop让内网穿透像点鼠标一样简单！

发表于2025-08-12|更新于2026-11-08|自建服务
|总字数:745|阅读时长:3 分钟|浏览量:

frp 很强，但每次编辑 frpc.toml、执行命令行并不友好。frpc-desktop 提供 Windows、macOS 和 Linux 图形界面，把客户端配置变成表单操作。

项目地址：https://github.com/luckjiawei/frpc-desktop/releases

版本提示： 本文截图和版本来自 2025 年 8 月。请从 Release 页面下载当前最新稳定版，并保持客户端与 frps 版本不要相差过大。

一、为什么用 frpc-desktop

  • 不需要手动编辑 frpc.toml；
  • 代理配置可视化，修改和排错更直观；
  • 支持多个代理同时管理；
  • 可设置开机自启动；
  • 支持常见 Windows、macOS、Linux 平台。

二、下载并启动

进入项目 Release 页面，根据系统选择安装版或便携版。Windows 常见包为 Frpc-Desktop-Setup-xxx.exe 或 Frpc-Desktop-xxx-win.zip。

安装或解压后启动，界面如下：

三、下载 frp

点击左侧菜单中的下载功能，选择 frp 版本。也可以导入已经下载好的 frp。

如果 frps 已经部署在云服务器上，尽量使用相近版本，避免配置兼容性问题。

四、配置服务器连接

点击左侧“齿轮”图标，选择 frp 版本，填写服务端信息：

  • 服务器地址：云服务器公网 IP；
  • 服务器端口：frps.toml 中的 bindPort，默认示例为 7000；
  • 认证令牌：与 frps.toml 中 auth.token 保持一致；
  • 其他选项保持默认。

保存配置。

五、添加代理

进入“代理”页面，点击“添加代理”。

以穿透内网 Web 服务为例：

配置项示例值说明
代理名称青龙面板自定义名称
类型TCP常用于端口映射
内网地址192.168.3.17NAS 或服务所在主机 IP
内网端口5700本地服务端口
外网端口8098云服务器上对外端口

六、启动并验证

回到主界面，点击“启动”。代理状态显示已启动后，即可访问。

浏览器访问：

其他常见玩法：

  • TCP：远程桌面、SSH、NAS 管理页面；
  • UDP：DNS、游戏联机等场景；
  • 多代理：同时映射多个内网服务；
  • 开机自启动：在设置中开启。

七、安全提醒

  1. 不要把管理后台随意暴露到公网；
  2. 为 NAS、数据库和远程桌面设置强密码；
  3. 云服务器只放行需要的外网端口；
  4. 客户端令牌不要写入公开仓库或截图；
  5. 敏感服务建议再套一层 VPN 或访问控制。

总结

frpc-desktop 适合不想频繁编辑 TOML 文件的用户。它把 frp 客户端变成了图形化配置工具，日常新增、启停代理更方便。真正需要重视的仍然是令牌安全、端口收敛和被穿透服务本身的防护。
