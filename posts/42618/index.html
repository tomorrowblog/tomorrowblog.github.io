it-tools：程序员的瑞士军刀，你的在线工具箱！

发表于2025-05-22|更新于2026-11-08|实用教程
|总字数:1283|阅读时长:5 分钟|浏览量:

写代码时经常需要临时处理 JSON、Base64、URL 编码、时间戳或哈希值。如果每次都打开不同网站，不仅麻烦，还可能把敏感数据交给不可信的在线服务。

it-tools 把大量常用开发工具集中在一个界面中，既可以直接访问公开站点，也可以用自己的服务器或 NAS 部署。它就像一个程序员专用的“瑞士军刀”。

**版本提示：**文中截图和 Docker 示例来自 2025 年 5 月，软件界面和镜像版本可能已经变化。请使用官方最新稳定版，并以项目文档和实际界面为准。生产环境不建议长期使用 latest，应固定具体版本并定期升级。

项目地址：https://github.com/CorentinTh/it-tools

一、it-tools 的核心功能

  • JSON 格式化：格式化、压缩和校验 JSON；
  • Base64 编码/解码：处理接口参数和文本数据；
  • URL 编码/解码：处理中文、空格和特殊字符；
  • 时间戳转换：在 Unix 时间戳和日期时间之间转换；
  • 哈希计算：生成 MD5、SHA-1、SHA-256 等摘要；
  • UUID 生成：生成测试数据或唯一标识；
  • 文本比较：查看两段文本的差异；
  • 二维码生成：把 URL 或文本生成二维码；
  • 颜色转换：查看 RGB、HEX 等颜色值；
  • Markdown 预览：在线编辑和预览 Markdown；
  • 网络与开发辅助：IPv4 子网计算、Crontab 表达式、HTML 编码等。

哈希值主要用于数据校验和内容摘要，不是加密，也不能用来保护密码或敏感数据。

二、it-tools 的优势

  • 工具集中：不用在多个小网站之间来回切换；
  • 开源可自建：可以部署在自己的服务器或 NAS；
  • 界面简洁：功能分类清楚，搜索后直接使用；
  • 跨平台：有浏览器即可，不依赖特定操作系统；
  • 适合内网：自建后可在局域网中使用，减少外网依赖。

公开在线版适合普通格式转换和临时测试。涉及密钥、客户资料、内部配置或未公开代码时，优先使用自建实例，并确认服务是否在本地处理数据。

六、公开访问时的安全建议

如果只是在家里的局域网使用，直接通过 NAS IP 访问通常就够了。若要把 it-tools 暴露到公网，至少应做好：

  1. 使用 HTTPS；
  2. 增加登录认证或访问控制；
  3. 不要把管理端口直接暴露在公网；
  4. 定期更新镜像和反向代理；
  5. 不在公开实例中处理密码、Token 和客户隐私数据。

it-tools 本身是工具集合，不会替你决定数据是否敏感。部署方式和使用场景才是安全边界。

七、适用人群

  • 程序员：处理 JSON、编码、哈希和测试数据；
  • 网页设计师：转换颜色、生成二维码和预览 Markdown；
  • 系统管理员：计算子网、生成 Crontab 表达式；
  • NAS 用户：在内网部署一个随开随用的工具箱；
  • 经常处理文本和接口数据的人：减少临时找工具的时间。

八、总结

it-tools 的价值在于把高频、零散的小工具集中到一个页面中。临时使用可以直接打开在线版；重视隐私和稳定性，可以用 Docker 部署在自己的 NAS 或服务器上。

建议收藏官方项目地址，部署时固定版本、保留备份，并为公网访问增加认证和 HTTPS。这样既能享受在线工具箱的便利，也不会把敏感数据交给不可信的服务。
