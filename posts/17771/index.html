告别Nginx“配置地狱”！OpenResty Manager：可视化+高性能+安全，你的Web服务“管家”！

发表于2026-11-08|更新于2026-11-08|自建服务
|总字数:891|阅读时长:4 分钟|浏览量:

OpenResty 基于 Nginx，并通过 Lua 扩展出更丰富的 Web 能力。功能很强，但直接维护配置文件对新手并不友好。

OpenResty Manager 为 OpenResty 提供了现代化 Web 管理界面，可以通过可视化方式配置反向代理、证书、应用和站点。

项目地址：https://github.com/Safe3/openresty-manager

版本提示： 本文截图和命令来自 2025 年 9 月。管理界面、功能划分和版本权益可能变化，请以项目当前文档为准。远程安装脚本执行前应先查看内容。

一、OpenResty Manager 适合谁

  • 不想手写复杂 Nginx 配置的个人站长；
  • 需要快速配置 HTTPS 和反向代理的开发者；
  • 希望统一管理多个 Web 服务的 NAS 或小型服务器用户；
  • 没有专职运维团队的小型项目。

二、部署前准备

  • 一台 Linux 云服务器或 NAS；
  • 已安装 Docker 时可直接使用容器版；
  • 云服务器安全组放行 80、443；
  • 管理端口 34567 建议只对可信 IP 开放；
  • 如需域名访问，提前把 DNS 指向服务器。

四、登录管理后台

访问：

默认用户名为 admin。默认密码请以首次登录页面或官方当前文档为准，不要继续使用公开示例密码。登录后立即修改密码。

安全提示： 34567 是管理入口，不建议直接对全网开放。优先使用防火墙白名单、VPN 或 Cloudflare Access 限制访问。

五、申请 SSL 证书

先把域名的 A 或 CNAME 记录指向 OpenResty Manager 所在服务器。

进入证书管理，选择申请 Let’s Encrypt 免费证书，或上传已有证书。

六、安装应用

进入应用商店，可以选择一键安装 WordPress 等应用。

七、配置上游和站点

添加上游

进入上游管理，为应用或服务添加后端地址，并可按需配置负载均衡。

新建站点

进入站点管理，点击“新建站点”，填写域名、证书和上游。

验证访问

保存后访问站点域名，确认页面和 HTTPS 正常。

八、高级功能

部分节点管理、节点分组和 Web 安全能力可能需要专业版。使用前先确认当前版本的授权范围和价格。

九、上线前的安全清单

  1. 修改默认管理员密码；
  2. 限制 34567 管理端口；
  3. 只开放 80、443 等必要业务端口；
  4. 定期备份证书、站点和容器数据；
  5. 固定镜像版本，升级前查看版本说明；
  6. 远程安装脚本先审查，再执行。

总结

OpenResty Manager 把证书、上游、站点和反向代理配置集中到可视化界面中，适合不想反复手写 Nginx 文件的用户。它降低了操作门槛，但管理端口、管理员密码和容器升级仍然需要认真维护。
