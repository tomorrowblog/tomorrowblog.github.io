内网穿透系列（四）：内网穿透搞不定？试试 zeronews 零讯！简单到离谱！

发表于2025-08-28|更新于2026-11-08|自建服务
|总字数:704|阅读时长:3 分钟|浏览量:

如果不想租云服务器、不想配置 frp，也不想开路由器端口，可以试试 ZeroNews 零讯。它在公网提供中转服务，内网设备运行 Agent 后即可映射服务。

版本提示： 本文截图和界面来自 2025 年 8 月。ZeroNews 的套餐、域名格式、带宽和连接数限制可能变化，请以官网当前说明为准。

一、ZeroNews 的特点

  • 客户端安装后配置域名、协议、内网地址和端口；
  • 不需要公网 IP，也不需要修改路由器端口映射；
  • 自动提供 HTTPS 域名；
  • 支持 HTTP/HTTPS/TCP 等常见场景；
  • 免费额度可满足轻量个人用途。

二、准备工作

  1. 注册 ZeroNews 账号；
  2. 记录授权码 Token；
  3. 确认内网服务的 IP 和端口；
  4. 在内网设备上安装 ZeroNews Agent。

官网：https://www.zeronews.cc/

三、安装 Agent

本文以极空间 NAS 演示。根据设备类型选择对应客户端或 Docker 方式安装。

官方文档见 https://docs.zeronews.cc/jkjnas。

安装成功后，ZeroNews 控制台应显示 Agent 已上线。

四、添加域名端口

进入“域名端口”，添加一个公网访问入口：

  1. 自定义域名前缀；
  2. 选择协议，例如 HTTPS；
  3. 选择端口；
  4. 确认创建。

五、配置映射

创建映射时需要填写：

  • Agent：选择刚才上线的设备；
  • 协议：例如 HTTPS；
  • 域名：选择上一步创建的域名；
  • 带宽：按套餐和需求填写；
  • 内网地址：如果服务在 Agent 所在主机，可用 127.0.0.1；服务在其他主机时填写真实内网 IP；
  • 端口：内网服务端口，例如 5700。

保存后，ZeroNews 会显示公网访问地址。

浏览器访问该地址即可打开内网服务。

六、常见用途

  • 远程访问 NAS 管理页面；
  • 临时演示本地开发服务；
  • 访问家庭内网的 Web 应用；
  • 映射远程桌面或 TCP 服务，但需要额外注意安全。

七、安全提醒

内网穿透会把服务暴露到公网，务必注意：

  1. 被映射服务使用强密码和最新版本；
  2. 非必要不暴露数据库、SSH、远程桌面；
  3. 只映射需要的服务端口；
  4. 关注免费版带宽、连接数和域名限制；
  5. 敏感服务建议叠加访问控制或 VPN。

总结

ZeroNews 适合临时需求和个人轻量项目，配置比 frp 和 Cloudflare Tunnel 更简单。它省去了公网服务器和证书配置，但你需要在速度、免费额度和安全暴露之间做好取舍。
