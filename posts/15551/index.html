内网穿透系列（五）：EasyTier异地组网，让你的设备“近在咫尺”！

发表于2025-09-13|更新于2026-11-08|自建服务
|总字数:958|阅读时长:4 分钟|浏览量:

想在外面访问家里的 NAS，或者让不同地点的设备像在同一个局域网里工作？EasyTier 可以把 Windows、Linux、macOS、手机和 NAS 组成一个虚拟局域网。

项目地址：https://github.com/EasyTier/EasyTier

版本提示： 本文截图和命令来自 2025 年 9 月。EasyTier 更新较快，请使用官方最新稳定版，并按当前文档调整参数。

一、异地组网适合什么场景

  • 在外访问家里 NAS、摄像头或管理面板；
  • 多地设备访问共享文件；
  • 分支机构连接内部系统；
  • 和朋友组建虚拟局域网玩联机游戏。

传统 VPN 方案通常需要公网 IP 和复杂路由配置。EasyTier 可以通过共享节点协调连接，并在条件允许时建立点对点通道。

二、EasyTier 的工作方式

可以把 EasyTier 理解成给每台设备分配一张“虚拟身份证”：

  1. 所有节点连接到同一个网络；
  2. 每个节点获得一个虚拟 IP；
  3. 节点之间尽量建立点对点连接；
  4. P2P 不通时，通过公共节点或自建节点中转；
  5. 传输使用加密通信。

三、准备节点

至少准备两台设备。可以使用公共共享节点，也可以自建节点。

如果自建共享节点，请参考官方文档：

https://easytier.cn/guide/network/host-public-server.html

从 GitHub Releases 或官网下载最新版本：

  • GitHub：https://github.com/EasyTier/EasyTier/releases
  • 官网：https://easytier.cn/guide/download.html

十一、安全建议

  1. 网络密码使用长随机字符串；
  2. 不同用途可以拆分多个网络；
  3. 不需要自动更新时关闭 Watchtower，避免不可预期升级；
  4. 自建节点要限制访问并保持更新；
  5. 敏感服务仍需账号密码、访问控制或 VPN 策略。

更多内容见 EasyTier 官方文档。

总结

EasyTier 适合多设备互联和远程访问 NAS，配置比传统 VPN 更简单。部署完成后，优先检查虚拟 IP 连通性、网络密码强度和各节点服务本身的访问控制。
